# CrimeMind — AI-Powered Crime Investigation Intelligence Platform

CrimeMind is a production-quality, enterprise-grade investigative intelligence platform designed for authorized law enforcement, federal agencies, and digital forensics task forces. It synthesizes multimodal evidence across surveillance feeds (CCTV), call detail records (CDRs), financial transaction logs, witness statements, and forensic disk images into a unified semantic graph and geotemporal matrix.

---

## 🎨 Design System & Visual Aesthetics

- **Enterprise AI & Cinematic Direction**: Built around an ultra-dark background (`#07080B`), sleek obsidian surfaces (`#0C0E14`), subtle crimson/neon red accents (`#FF2A42`), and thin 1px glassmorphic borders (`rgba(255, 255, 255, 0.08)`).
- **Zero Excessive Cyberpunk / Not Gaming**: Strictly professional typography (Inter / Manrope), soft shadows, and realistic depth optimized for continuous forensic analysis without cognitive fatigue.
- **Epistemological Distinction**: Every visual datapoint is strictly color-coded and badged across three forensic confidence tiers:
  - `RAW DATA`: Cryptographically verified immutable telemetry (gray).
  - `AI FINDING`: Algorithmic inference generated by neural vision or graph models (crimson glow + confidence %).
  - `HUMAN VERIFIED`: Sign-off by lead investigator with badge number and timestamp (emerald green).
- **Movement Inferences Safeguard**: Inferred geotemporal paths are strictly labeled `"Observed"`, `"Potential connection"`, `"AI-inferred"`, or `"Requires verification"`.

## 🚀 Running the Application Locally

### 1. Install Dependencies
```bash
cd frontend
npm install
```

### 2. Start Vite Development Server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 3. Build for Production Bundle
```bash
npm run build
```

## ⚡ Key Modules & Capabilities

1. **3D Hero Intelligence Visualizer**: Rotating translucent isometric cube with vertex pins and floating glass cards (`LIVE EVENT`, `AUDIO SIGNAL`, `CCTV`, `EVIDENCE MATCH`, `LOCATION ANALYSIS`).
2. **LangGraph 9-Agent DAG Workflow**:
   - `Planner`: Orchestrates query decomposition.
   - `Evidence Agent`: Multimodal vector retrieval.
   - `Case Agent`: Case dossier cross-correlation.
   - `Person Agent`: Biometrics, aliases, and co-conspirators.
   - `CCTV Agent`: Optical facial descriptors and ANPR license OCR.
   - `Graph Agent`: Topology traversal & pathfinding.
   - `Law/Policy Retrieval Agent`: Statute verification & warrant compliance.
   - `Timeline Agent`: Chronological event sequencing.
   - `Synthesis Agent`: Final hypothesis reduction.
3. **Voice & Hands-Free Mode**: Real-time microphone listening, animated visualizer waveform, and audio playback streaming for tactical field operations.
4. **Interactive Relationship Graph**: Directed SVG canvas with 8 node categories (Person, Case, Evidence, Vehicle, Location, Call, Transaction, Incident), 9 relationship edge types, search/highlighting, shortest-path calculation (`Alt + Click`), and side drawer inspection.
5. **CCTV Optical Matcher**: Allows investigators to submit reference photographs or license numbers to perform synthetic similarity matches across video archives with confidence scores and verification warnings.
